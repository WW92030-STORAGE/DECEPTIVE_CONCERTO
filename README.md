# DECEPTIVE_CONCERTO

Partially a remake of my older game DECEPTIVE_SYMPHONY, partially an experiment in Portals.

First person survival horror game inspired by Dark Deception by Glowstick Entertainment.

WHAT IS INCLUDED IN THIS DEMO (All of this is subject to change.)

-There are currently 2/4 levels but there may or may not exist more.

-Levels vary in difficulty but generally increase as you go along.

-Due to the nature of this game, pausing during levels is strictly forbidden.

-Credits for certain aspects (BGMs, textures, mechanics, etc.) are in the CREDITS.TXT on the GitHub repo.

CONTROLS

WASD to move. 

X to toggle the minimap and Z to zoom. 

LMB/RMB to activate powers/interact. 

SPACE to jump. 

(MIGHT REMAP POWERS TO Q/E IN A LATER BUILD)

IMPORTANT

Make sure you cycle through your powers each level. This game does not follow the same progression as Dark Deception.
